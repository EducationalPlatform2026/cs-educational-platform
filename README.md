# cs-educational-platform
# here project description
This project aims to develop an educational platform for managing Computer Science courses, solving programming exercises, and performing automatic evaluation of submitted code.
The platform addresses the lack of a unified system where students and instructors can interact efficiently during programming courses. Currently, tools are often fragmented (separate platforms for assignments, grading, and communication), leading to inefficiencies and poor user experience.
The target users include university professors and teaching assistants, high school teachers, as well as students and pupils studying programming.
The system is needed to centralize course materials, automate the evaluation process, reduce manual grading effort, and provide immediate feedback to learners. It also allows students to track their progress and improves the overall learning experience.
